### B01 设备使用申请是否审批，申请与授权的联系

- **涉及**：UC1、UC6；类图“设备使用申请”“设备权限关联”。
- **问题**：用例图只有“申请使用设备”，没有规定是否审批、由谁审批，也没有规定申请与授权之间的关系。
- **选项**：
  - A：只登记申请。管理员执行 UC6 时可以查看申请作为参考，申请与授权不建立数据联系。
  - B：同 A，但授权可以注明来源申请（0..1）。申请记录相应显示“已据此授权”。
  - C：申请须审批，批准后自动生成授权。审批是否属于 UC6 需确认；若作为新用例，**需改基准**。
- **影响**：选 A/B 不改用例关系，B 在 ER 中增加一条可选联系（候选 ER 图中的虚线）。选 C 时还需增加申请状态（待审批/通过/驳回）和审批人字段，并补 UC1/UC6 活动图。
- **建议**：B。不新增流程，也能看出授权依据。
- **确认结果**：待确认

### B02 权限粒度、有效期、共享与独占规则

- **涉及**：UC2、UC6、INC1；类图“设备权限关联”。
- **问题**：图中未规定授权到什么粒度、是否有期限，也未规定多人能否同时操作同一设备。
- **选项**（粒度）：A 设备级，有授权即可执行该设备全部操作；B 设备级加操作类型白名单；C 在 A 或 B 上增加有效期。
- **选项**（占用）：D 不做占用控制，同一设备的指令由系统串行下发；E 同一时刻只允许一人使用。E 需要占用与释放机制，接近“借还/排期”，有超出范围的风险。
- **影响**：决定权限关联的字段、INC1 的判定逻辑、UC6 界面，以及 UC2 拒绝路径的种类。
- **建议**：A + D；有效期按需后加。
- **确认结果**：待确认

### B03 工单管理动作、状态集合和关闭条件

- **涉及**：UC4、UC8、UC11、EXT1；图 2-17；类图“故障工单”。
- **问题**：UC8“管理故障工单”和 UC11“处理故障工单”的边界，以及工单何时结束，图中都没有规定。
- **选项**：
  - A：沿用图 2-17 的候选三态，不设关闭。
  - B：增加“已关闭”。运维人员提交处理信息后，由管理员在 UC8 中确认关闭。UC8 的动作限于查看、修正信息、关闭。
  - C：运维人员在 UC11 中直接关闭。UC8 只保留查看与修正。
  - 指派运维人员、多级审批等不在任何选项中。如需要，**需改基准**。
- **影响**：涉及状态图 2-17、工单字段、UC8 与 UC11 的权限划分，以及 B04 去重规则判断“未关闭工单”的依据。

- **确认结果**：待确认

### B04 监测周期、异常判据、未知状态及去重规则

- **涉及**：UC9、EXT1；图 2-14、2-16。
- **问题**：图中只给出扩展条件“监测到设备状态异常”，没有给出何时监测、怎样算异常、通信失败怎样处理、是否重复建单。
- **选项**：
  - 触发方式：A 运维人员手动发起；B 系统定时轮询，运维人员查看结果；C A 与 B 并存。
  - 判据：按设备类型配置判据（例如设备上报错误码、读数越界）。具体数值由用户按设备给出。
  - 未知状态：D 不算异常（与当前图一致）；E 连续若干次取不到状态后视为异常。
  - 去重：F 同一设备已有未关闭的监测工单时不再新建；G 每次异常都建单。
- **影响**：B 或 C 需要后台定时任务。E 会改变图 2-14 与 2-16 中“通信失败不进入异常判断”的现有表述。F 依赖 B03 的关闭状态。
- **建议**：C + D + F；周期与阈值由用户给出。
- **确认结果**：待确认

- **问题**：UC10“执行自动化运维”没有规定动作清单、触发方式和失败处理。
